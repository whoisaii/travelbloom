# TravelBloom

Travel recommendation site with Home, About Us and Contact Us pages.

- Search: beach/beaches, temple/temples, country/countries; case-insensitive place names.
- Clear removes results and resets the input.
- Locally stored destination photography, credited on image_credits.html.
- Contact form opens an email client; the example address is a clearly marked demo placeholder.

Public site: https://whoisaii.github.io/travelbloom/

Run locally with `python3 -m http.server 8080`. No build step is needed.
